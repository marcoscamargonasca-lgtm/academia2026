ACADEMIA PASILLO DEL REY
1. Crea un proyecto en Supabase.
2. En SQL Editor ejecuta supabase_setup.sql.
3. Copia Project URL y anon key en index.html donde dice PON_AQUI...
4. Sube index.html a GitHub Pages.
5. Para vender libros con pago automático habrá que conectar una pasarela de pago y una cuenta comercial.
